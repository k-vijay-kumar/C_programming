# C Compilation Flow

A typical GCC build passes source through preprocessing, compilation to assembly, assembly to an object file, and linking to an executable. GCC can run several stages in one command; the commands below show each stage explicitly.

Run these commands from the directory containing `test.c`:

```sh
# Preprocess C and expand included headers and macros.
gcc -E test.c -o test.i

# Compile C to assembly.
gcc -S test.c -o test.s

# Assemble to an object file.
gcc -c test.s -o test.o

# Link the object file into an executable.
gcc test.o -o test.exe

# Run the program.
./test.exe

# Display executable section sizes (not a process memory map).
size test.exe
```

Replace `test` with the chosen source-file name. A program may use multiple object files and libraries at the link stage.
